## 工作约定

- 所有产出使用**中文**；引用外部信息必须附来源 URL
- 严格区分**品牌自述口径**与**第三方证据**，不把自家宣传当证据
- 环境限制（两条，影响所有结论的可信度上限）：
  1. **WebFetch/curl 抓取外部网页一律被代理 403**（含 zxd-hotel.com、36氪、携程、住建部）。
     **没有任何一篇原文被打开过**，全部内容来自搜索引擎的标题+摘要，正式对外引用前需人工复核原文
  2. **单会话 WebSearch 配额 200 次**。深度调研的前 3 个角度就耗尽了配额，导致「竞品/法规/市场/资本/招商反馈」
     5 个角度 0 次检索，其内容来自仓库既有材料与模型内部知识，**条文编号与数值未经核证**
- 结论分级标注：**【实证】**第三方可查 · **【自述】**品牌口径 · **【推断】**基于已有材料的推理 · **【待核证】**未经验证
- 搜索引擎为美国索引，**小红书/抖音/B站/知乎/大众点评/美团的站内内容基本检索不到**，需人工在 App 内导出
- 仓库存放位置：受 GitHub App 权限限制（无 `create_repository` 权限），暂时寄存在
  `d01031384647-a11y/intentcomputimg` 仓库的 `claude/zhu-xiaoding-strategy-xdvbs7` 分支下的本目录。
  股东若在 GitHub 上手动新建一个空仓库并授权，可随时整体迁出
