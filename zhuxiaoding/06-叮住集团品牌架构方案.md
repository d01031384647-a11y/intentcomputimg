## 1. 一句话结论

> **五个品牌能不能同时开，不取决于品牌怎么命名，取决于总部能不能把已有的「无人化三件套」从省人力的工具，改造成零驻店管控加盟商的武器。**
> 做到了，五个品牌都能开，而且总部成本不随门店数线性增长；做不到，每多开一个品牌就多一份失控。

OYO 在中国的崩塌有两个直接死因：**加盟商跳单私客、阳奉阴违地乱调价**，以及**驻店地推团队的成本随门店数线性增长、规模越大亏越多**。这恰好就是股东提出的两个担心。

**叮住比 OYO 多的、也是唯一但决定性的一点，是 OYO 当年不具备的技术条件：**

| 已有能力 | 在直营店的用途 | 在加盟店的战略价值 |
|---|---|---|
| 智能门锁 | 省掉发卡收卡 | **与 PMS 绑定，无订单不发码 —— 物理上杜绝跳单私客** |
| 人脸核验 | 满足公安实名登记 | **真实入住人数回传总部 —— 加盟商无法瞒报营收** |
| 自助入住 | 省掉前台人力 | **客人不接触加盟商 —— 没有截流的机会窗口** |

OYO 没有这三样，所以只能靠人盯人，靠地推驻店，最终被成本拖垮。**叮住有，所以可以做到零驻店。这是本方案全部机制设计的支点。**

## 2. 集团与法人架构

```
                    ┌─────────────────────────┐
                    │      叮住集团（品牌主体）  │
                    │  商标持有 · 标准制定 · 渠道垄断 │
                    └───────────┬─────────────┘
                                │
        ┌───────────────────────┼───────────────────────┐
        │                       │                       │
┌───────▼────────┐   ┌──────────▼──────────┐   ┌────────▼─────────┐
│  品牌运营公司     │   │ 叮住资产运营管理有限公司 │   │   叮住会（会员中台）  │
│  五个品牌的        │   │  ① 管理输出           │   │  全品牌通用会员      │
│  产品标准/供应链/  │   │  ② 资产换股权合资      │   │  私域 · 复购 · 互导  │
│  培训/督导        │   │  ✗ 不做包租二房东      │   │                  │
└────────────────┘   └─────────────────────┘   └──────────────────┘
```

**三点设计说明：**

1. **商标与渠道账号必须留在集团主体，不下放到任何品牌公司或项目公司。** 这是所有管控手段的法律与技术基础，一旦下放，后面所有防火墙全部失效。
2. **资产公司排除包租二房东**，与股东 ⑥ 一致。长约租金在 RevPAR 下行周期是最危险的负债，Selina 的死因正是「高租金长约 + 重投入 + 低 ADR」三件事叠加。
3. **「叮住 / 盯住」的谐音不必回避，反而应该主动用。** 集团名主要面向 B 端（资产方、加盟商、投资人），"盯得住资产、盯得住品质"是正面语义。C 端只见品牌名，不见集团名。

## 3. 品牌矩阵：两个维度、五个位置

### 3.1 矩阵结构

真正区分五个品牌的是**两个维度**，不是五种产品：

**维度一（对客人可见）：房型** —— 铺位 / 4㎡ 无独卫单间 / 6–8㎡ 带独卫单间
**维度二（对加盟商可见）：谁在运营** —— 总部全服务运营 / 业主自运营

|  | **大物业**（1000–2000㎡）<br>总部运营 · 全服务 | **小物业**（300–500㎡）<br>业主自运营 · 自助 |
|---|---|---|
| **6–8㎡ 带独卫** | **住大叮** ｜ 150–300 元 | **叮舍** ｜ 130–260 元 |
| **4㎡ 无独卫** | **住小叮** ｜ 80–150 元 | **叮栈** ｜ 70–140 元 |
| **多人间铺位** | — | **叮铺** ｜ 60–100 元（存量宾馆改造，两种规模皆可） |

### 3.2 五个品牌的完整定义

| | **住小叮** | **住大叮** | **叮铺** | **叮栈** | **叮舍** |
|---|---|---|---|---|---|
| **定位** | 同价位最干净 | 汉庭进不去的位置，汉庭一半的价格 | 存量宾馆的第二次生命 | 自有物业的最小启动 | 自有物业的升级款 |
| **房型** | 4㎡ 单间 无独卫 | 6–8㎡ 单间 带独卫 | 多人间铺位 | 4㎡ 单间 无独卫 | 6–8㎡ 单间 带独卫 |
| **价格带** | 80–150 | 150–300 | 60–100 | 70–140 | 130–260 |
| **物业** | 1000–2000㎡ 整层整栋 | 1000–2000㎡ | 停业宾馆 / 招待所 / 老旧酒店 | **300–500㎡ 业主自持** | **300–500㎡ 业主自持** |
| **运营** | 总部派店长 | 总部派店长 | 视规模定 | **业主自运营** | **业主自运营** |
| **服务** | 24h 前台 + 公区 + 洗衣房 | 24h 前台 + 公区 + 洗衣房 | 前台 + 公区 | 自助入住，无大堂无公区 | 自助入住，无大堂无公区 |
| **状态** | 43 家已签/已开 | 已签 3 家，0 开业 | 洽谈中 | 未启动 | 未启动 |
| **开放时点** | 现在 | 首店验证后（见第 7 节） | Gate 2 之后 | Gate 3 之后 | Gate 3 之后 |

### 3.3 命名说明

**已定：** 集团 = 叮住集团 · 资产平台 = 叮住资产运营管理有限公司 · 主力双品牌 = 住小叮 / 住大叮 · 会员 = 叮住会（原「得住会」随集团更名）

**待股东定的两处：**

**（1）多人间品牌：「小小叮」还是「叮铺」？**

股东原意是叫「小小叮」，作为住小叮之下的产品线。这里有一个必须先讲清楚的取舍：

> **住小叮当前最核心的差异化是「比青旅私密、比酒店便宜」——共享卫浴但独立单间。多人间会直接摧毁"比青旅私密"这一半。**
> 而 Agoda 上住小叮已经被归类到青旅【实证】，说明这个认知边界本来就脆弱。名字里带「小叮」，客人会默认是同一个东西，多人间的认知会顺着名字回流到住小叮。

| 方案 | 优点 | 代价 |
|---|---|---|
| **小小叮** | 认知成本最低、招商最好讲 | 青旅认知回流住小叮；多人间管理事故（失窃/噪音/性别混住）会直接传导 |
| **叮铺**（推荐） | 「铺」= 床铺/铺位，产品形态一目了然；不含"小叮"不会误认；仍在叮字系享受集团背书 | 需要独立建立认知 |

**推荐「叮铺」。** 理由是这个品牌恰恰是五个里管理难度最高、最容易出事的一个（陌生人同房、失窃、噪音、性别管理、接手别人的消防与产权历史），**最需要和主品牌之间有一道名字上的隔离**。

**（2）小物业双品牌：「叮栈 / 叮舍」**

- **叮栈**（无独卫）——「栈」自带小规模、街边客栈、自家人打理的语感，正好匹配业主自运营
- **叮舍**（带独卫）——「舍」为房舍，比「栈」稍正式，对应带独卫的升级

两个字都好念、好写、好上门头，这对夫妻店很重要。且都不含「小叮」「大叮」，符合股东 ⑤ 的"独立品牌名 + 集团背书"。

**统一背书格式：** 门头与所有物料使用「**叮住集团旗下**」小字，不使用「住小叮旗下」——避免风险沿品牌链条向上传导。

### 3.4 为什么小物业版价格更低？——是服务分层，不是物业分层

客人不知道也不关心物业多大。**能对客人讲通的差价理由只有一个：服务减配。**

- 住大叮 / 住小叮：24 小时前台、公共区域、洗衣房、行李寄存
- 叮舍 / 叮栈：全自助入住、无大堂、无公区、无 24 小时人工

所以定价规则是「**叮舍 = 住大叮减 20–25%**」「**叮栈 = 住小叮减 15–20%**」，理由写在 OTA 页面上，客人自己能判断值不值。

## 4. 四道防火墙

多品牌最大的风险不是外部竞争，是**自己人打自己人**。四道墙都必须做成系统硬约束，而不是写进手册。

### 墙一 · 价格墙（防品牌互食）

住小叮 80–150 与住大叮 150–300 在 150 这个点是重叠的。**旺季住小叮卖 150、淡季住大叮也卖 150 时，同样的钱一个共享卫浴一个带独卫，客人 100% 选住大叮——住小叮的高价房会永久性卖不动。**

写死三条，**在 PMS 里做成保存校验，越界无法提交**：

1. 同城同期，**住大叮最低门市价 ≥ 住小叮最高价 × 1.3**
2. 同城同期，**住大叮 ≥ 叮舍 × 1.25**；**住小叮 ≥ 叮栈 × 1.25**
3. **叮铺最高价 ≤ 住小叮最低价**

每个品牌按城市设价格带上下限，由总部收益团队按季调整。**门店无权越界，加盟商无权越界。**

### 墙二 · 渠道墙（防加盟商乱调价 —— 股东担心之一）

> **合同罚则是事后追责，控渠道才是事前阻断。加盟商真乱调价时，罚款和解约都发生在损失之后。**

1. **所有 OTA 门店账号由集团注册、集团持有，加盟商无登录权限**
2. **直销只有一个入口**：叮住会小程序，加盟商不得自建任何售卖渠道
3. **PMS 由集团统一部署**，加盟商是使用者不是管理员，价格字段只读
4. **收单账户在集团**，门店无现场收款权限，结算按周期回付

第 4 条是最重要的一条：**只要钱不先经过加盟商的手，跳单私客在财务上就无利可图。**

### 墙三 · 区域墙（防自家门店互踩）

- **立即自查已签 43 家的合同里是否含区域独家/区域保护条款**【待核证】。若有，同商圈开任何新品牌都可能直接违约
- 新签合同统一改为**按品牌授予保护半径**：同品牌保护，**跨品牌不保护**，并在签约时明确告知
- 保护半径建议按城市分级（北京核心区 800m / 一般区域 1.5km）【建议值，待股东按实际商圈密度定】

### 墙四 · 责任墙（防单店事故传导全品牌）

- 五个品牌**分设独立运营主体**，加盟合同的相对方是各品牌公司，不是集团
- 各品牌**独立投保**公众责任险，保额下限写进加盟准入
- 对外统一口径：**集团背书品牌标准，不背书单店经营行为**
- **叮铺因管理难度最高，必须首店自营、跑满一年再考虑加盟**

## 5. 500㎡ 以下这一档：一个绕不开的硬约束

股东对轨道选择的回复是"两个都可以商量"。但在设计两条轨道之前，有一个测算结论必须先摆出来，因为它决定了这一档能不能做。

### 5.1 测算：小物业 + 租赁物业 = 不成立【推断】

按股东给的单床实投 3.2–4 万，以 500㎡ / 55 床的叮栈为例：

| 项 | 大店（住小叮 1000㎡ / 100 床） | 小店（叮栈 500㎡ / 55 床，**租赁**） |
|---|---|---|
| 年收入 | 388 万【内部材料】 | 154 万（ADR 90 × 出租率 85%） |
| 租金 | 1000㎡ × 3.5 元 × 365 = **128 万（占 33%）** | 500㎡ × 4.0 元 × 365 = **73 万（占 47.5%）** |
| 人力 | 雇员 | **0（业主自运营）** |
| 其他（水电/物耗/OTA/总部费/税） | — | 约 51 万 |
| **年净利** | 143 万【内部材料】 | **约 30 万** |
| 投资 | 320–400 万 | 176–220 万 |
| **回本** | **2.2–2.8 年** | **6–7 年 ❌** |

**两个原因叠加：** ① 小物业租金单价更高、总收入更小，租金占比从 33% 恶化到 47.5%；② 前台、PMS、证照、督导这些固定成本不随面积缩小，小店摊不薄。

**结论：物业越小，投资门槛确实降了，但回报率降得更快，回本期反而拉长。对加盟商来说小店不是"更划算的入门款"，是"更差的生意"——算得过账的人不会签。**

### 5.2 唯一算得通的解：租金归零

同一个店，如果物业是**业主自持**：

| 项 | 金额 |
|---|---|
| 年收入 | 154 万 |
| 租金 | **0** |
| 人力 | **0（业主自运营）** |
| 其他成本 | 约 59 万 |
| **年净利** | **约 95 万** |
| 投资 | 176–220 万 |
| **回本** | **1.9–2.3 年 ✅** |

> **所以：叮栈 / 叮舍 的准入条件必须写死「业主自持物业」，不接受租赁物业。**
> 这不是偏好，是模型成立的前提。一旦放开租赁，招商越成功、暴雷越多。

而且这个约束恰好三线合一：

1. 股东说的"夫妻老婆店"**本来就是自己有房的人**
2. 直接接上"**中国资产大换仓**"的主线故事——不是去市场上抢租物业，是去**激活别人手里的死资产**
3. **企业介绍里已经有这个结构了**——四种合作模式中的「**物业联营合作 · 适配物业持有方 · 租金+分红联营模式**」（`research/raw/01-企业介绍.txt` 第 365 行起），现在只是把它从大物业下沉到小物业

### 5.3 两条轨道

| | **轨道 A · 特许加盟** | **轨道 B · 物业联营** |
|---|---|---|
| **对象** | 自持物业 **且** 有 100–220 万现金的小投资商 | 自持物业 **但没有现金**的业主 ← **真正的"夫妻老婆店"** |
| **谁出改造钱** | 业主 | 总部 / 资方 |
| **业主投入** | 100–220 万 | **接近零** |
| **收益** | 全部经营利润归业主，总部收特许费+持续费 | 净利分成；改造款从分成中优先回收 |
| **总部角色** | 品牌 + 标准 + 渠道 | 品牌 + 标准 + 渠道 + **资本** |
| **总部风险** | 低 | 垫资沉淀在他人物业里 |

**轨道 B 的分配结构建议：** 改造款回收期内净利 7:3（资方:业主），回收完毕后 5:5。以年净利 95 万测算，资方回收期约 **2.6–3.3 年**；业主零投入、期内年得约 28 万、期后约 47 万。

**轨道 B 的核心风险与解法：** 业主中途反悔，改造款已经沉淀在他的物业里。

- 合约期 10–15 年 + 提前终止时改造款加速偿还条款
- 条件允许时办理他项权利登记
- **但最有效的一条仍然是渠道墙**：业主赶走总部，同时失去全部订单来源。**渠道是资产保全手段，不只是管控手段。**

**轨道 B 的资金从哪来（三个来源，建议同时推进）：**

1. 集团自有现金流 —— 有限，只够打样
2. 财务投资人认购单店或资产包 —— 这就是股东 ⑥ 说的"资产换股权"，也是叮住资产运营管理公司的主战场
3. **装配式模块供应商做经营性租赁** —— 你们主打"标准化装配式模块，单床位造价极致控制"【自述】。**如果模块供应商愿意以设备租赁形式介入，改造资金里最大的一块可以变成租金分期，总部垫资压力大幅下降。这条最值得先谈，因为它不稀释股权。**

**建议：两轨都开，但先跑轨道 B。** 轨道 A 在小物业上对加盟商吸引力弱（即便自持物业，也要一次性拿出 100–220 万），招商会很吃力；轨道 B 才真正把门槛降到夫妻店够得着的位置，也直接服务"资产大换仓"的主线。

## 6. 控价与品控：逐条拆解 OYO 的死因

### 6.1 核心思想：渠道即抓手

> **总部对加盟商唯一真正有效的杠杆不是合同，是流量。**
> 不听话 → 降低渠道曝光权重 → 掉客 → 自己回来。
> 这比罚款有效得多，执行成本接近于零，而且不需要打官司。

品控处置阶梯：**预警 → 降权（削减渠道曝光）→ 停止分发新订单 → 摘牌**。前三级全部由系统自动执行，不需要人到现场。

### 6.2 六条死因对照

| OYO 死因 | 具体表现 | 叮住的反向设计 |
|---|---|---|
| **加盟商跳单私客** | 客人到店线下成交，绕开系统 | ① 智能门锁与 PMS 绑定，**无订单不发码**<br>② 人脸核验数据回传，真实入住人数总部可见<br>③ 门店无现场收款权限，支付走集团收单 |
| **私自调价、阳奉阴违** | OTA 上乱标价、私下加价 | ① OTA 账号集团持有，加盟商无登录权<br>② PMS 价格字段对门店只读，越界无法保存<br>③ 直销仅叮住会小程序一个入口 |
| **保底承诺拖垮现金流** | 承诺保底收入，达不到自己贴 | **绝不做任何形式的收入保底或投资回报承诺**。这同时是《商业特许经营管理条例》的合规红线，现有材料里的"3 年回本"表述也应一并按预测口径改写（见 `05` 第 6 节） |
| **驻店团队成本线性增长** | 规模越大亏越多 | ① 现场运营 100% 由业主承担，**总部零驻店**<br>② 总部只做渠道 / 定价 / 远程品控——**边际成本递减**<br>③ 巡检用摄像头 + 工单 + 神秘顾客替代驻店 |
| **品控崩塌** | 挂牌不改造，品质参差 | ① **不接受"只挂牌"**，必须按标准改造并通过竣工验收<br>② **未验收不上线渠道**<br>③ 差评率、保洁工时、复购率进系统看板，触发阈值自动降权 |
| **规模优先于单店盈利** | 疯狂签约，大量门店亏损 | **Gate 制度**（第 7 节）：前一品牌未跑通，不开下一个 |

### 6.3 一条硬性前置条件

> **在总部收益管理团队与统一 PMS / 渠道管控能力到位之前，不开放任何一个"业主自运营"品牌的加盟。**

叮栈和叮舍的全部风险都压在这一个能力上。**它没建成之前，这两个品牌一家都不能签。**

需要股东确认的现状：**目前 43 家门店的房价是谁在调、怎么调？有没有独立的收益管理团队？** 如果现在还是各店自行调价或人工看竞品，那"总部垄断定价权"就不是一个制度问题，而是一个从零建团队的问题，必须排进时间表。

## 7. 上市节奏与准入门票（Gate 制度）

**原则：每一个新品牌都必须先用直营验证，跑到指标才允许加盟；前一个 Gate 不过，后一个不开。**

```
现在 ──────────────────────────────────────────────────────────────►
  住小叮  ████████████████████████████████████████  持续放量（43 家已签/开）
  上海首店 ██  出京验证（即将开业）
  住大叮   ███  已签 3 家 → ⚠️ 首店必须先跑出数据
                    │
                  Gate 1
                    ▼
  住大叮放量        ████████████████████
                              │
                            Gate 2
                              ▼
  叮铺（首店自营）              ██████████████
                                      │
                                    Gate 3
                                      ▼
  叮栈 / 叮舍                          ████████████
```

| Gate | 门槛 | 通过后开放 |
|---|---|---|
| **Gate 0**<br>（当前最紧急） | 住大叮**首店开业并连续运营 3 个月**：出租率 ≥80%、ADR ≥180 元、GOP ≥25% | 已签 3 家按序开工 |
| **Gate 1** | 住大叮 3 家全部开业且达标；上海首店满 3 个月达标 | 住大叮全面招商 |
| **Gate 2** | 住大叮累计 ≥8 家开业；**叮铺首店自营满 6 个月**且无重大管理事故 | 叮铺对外招商 |
| **Gate 3** | 叮铺跑通低人力模型；**总部收益管理团队到位、PMS 价格硬约束上线、OTA 账号全部收归集团** | 叮栈 / 叮舍启动首店（自营或轨道 B） |

### ⚠️ 关于住大叮已签 3 家的专门提示

**产品未经任何运营验证就复制了 3 份，这是当前五个品牌里最集中的单点风险。** 三家如果同时开工，一旦产品定义有误（房型尺寸、独卫排风、隔声、造价），错误会同时发生在三个地方，且已经付出了不可逆的工程成本。

**建议：3 家错开开工，第一家跑满 3 个月拿到真实数据后再动第二家。** 如果合同已约定工期无法错开，至少要把第一家的竣工复盘变成后两家的强制变更输入。

另外需要股东核实：**住大叮单店投资约为住小叮的 1.5–2 倍**（带独卫要做上下水、防水、排风、洁具，单间造价显著高于 4㎡ 无独卫床位）【推断】，**回本期也会更长**。已签的 3 家加盟商对这一点的预期是否已经对齐？如果他们是按住小叮的回本预期签的，开业后会有纠纷。
