## 1. 三处必须替换的措辞（合规）

| 原表述 | 问题 | 替换 |
|---|---|---|
| 「同一个价位里**最干净**的那一家」 | 广告法第 9 条绝对化用语 | **「同价位，我们只比干净」** |
| 「成本**最低**」「门槛**最低**」「**最**有力」 | 同上 | 「显著低于…」「更低的启动门槛」 |
| 任何回报数字 | 广告法第 25 条：招商广告须提示风险、不得作保证性承诺 | 标注「测算值 + 关键假设」，全篇设风险提示，保留「不作收益承诺」声明 |

> 「我们不做收入保底」这一条**必须保留**——在公开招商材料里主动声明不作收益承诺，是最有效的免责表述之一。

## 3. GOP 重算结论（股东第 8 条）

### 3.1 原表述存在术语错误

内部材料同时写着「GOP 30%+」与「年收入 388 万 / 年净利 143 万（扣租金后）」。
后者的利润率为 **36.9%**——而 GOP 是**扣租金前**的口径，扣租金后的利润率不可能高于它。
两个数字放在同一份材料里，懂酒店的听众一眼就能看出矛盾。

**判断：把「经营利润率」误称为了 GOP。而这个混用让集团低估了自己。**

### 3.2 反推真实 GOP

| 成本项 | 占营收 | 依据 |
|---|---|---|
| 人力 | 10–13% | 150:1 人房比 + 自助入住 |
| 能源 | 12–16% | 无窗客房全机械新风，新风量约为传统酒店两倍 |
| 物耗与洗涤 | 8–10% | 15–20 分钟/间高频保洁 |
| OTA 佣金 | 5–7% | 约 45% OTA 订单占比 |
| 维修 + 管理 + 系统 | 5–7% | |
| **运营成本合计** | **40–53%** | |
| **真实 GOP（扣租金前）** | **47–60%** | |

### 3.3 建议对外口径

> **GOP 45%+**（国际通用口径，扣除运营成本、租金前）
> **经营利润率 30%+**（扣除租金后）

两个数字都讲，术语各归各位。**比现在的「GOP 30%+」既更专业、也更高。**

## 4. 租金敏感性（内部使用，不进公开版）

股东确认北京租金 **2–5 元/㎡/天都有**。以 100 床 / 1000㎡ / 年营收 388 万、GOP 取中值 53%（206 万）测算：

| 租金 元/㎡/天 | 年租金 | 经营利润 | 经营利润率 | 回本（综合投资 350 万） |
|---|---|---|---|---|
| **2.0** | 73 万 | 133 万 | 34.3% | **2.6 年** |
| **3.0** | 110 万 | 96 万 | 24.8% | **3.6 年** |
| **4.0** | 146 万 | 60 万 | 15.5% | **5.8 年** |
| **5.0** | 183 万 | 23 万 | 6.0% | **15.1 年** |

### 两条结论

**① 租金 ≤ 3 元/㎡/天 是这个模型的生命线。** 4 元开始吃紧，5 元不成立。
建议把「租金占营收比」写成《选址要求规范》里的**第一道硬红线**，优先级高于面积、层高、地铁距离。

**② 这直接支撑了集团最核心的战略叙事：**

> **我们的核心竞争力不是把房间做小——房间做小谁都会。
> 是我们能拿到别人拿不到的物业价格。**

这句话同时解释了三件事：为什么利润率能高于同行、为什么定位是资产运营商而非酒店公司、为什么"存量物业改造能力"是三个底座之一。**建议作为第Ⅲ章的核心论点。**

### 公开版怎么讲

**不发布单一回本数字，改为讲方法论：**

> 「每一个项目的投资回报，取决于物业条件本身。我们不提供一个统一的数字，我们提供一套一店一算的测算方法——
> 租金占营收比、可运营床位数、客源结构，三个变量确定之后，模型自然成立或不成立。
> 我们宁可在签约前告诉你这个物业不合适。」

这既符合广告法（不作收益承诺），又比给一个数字更显专业。

## 5. Gate 制度改造（股东第 13 条）

**Gate 制度原义**：每个新品牌在对外放量前，必须先用直营店跑出一组硬指标，达标才进入下一阶段。
**要防的是**：品牌数量跑在验证前面 → 疯狂签约 → 大量门店亏损 → 口碑崩塌。这是连锁加盟行业最经典的失败路径。

**但原讲法不适合董事长演讲**，因为它隐含"我们还没准备好"。改造如下：

| ❌ 原讲法 | ✅ 定稿讲法 |
|---|---|
| Gate 准入门票 | **品牌成熟度管理机制** |
| 前一个品牌没跑通，不开下一个 | **每个品牌达到成熟度标准，才进入规模化复制阶段** |
| 我们还没验证 | **我们对品牌质量有纪律** |

- 对**合作方**：这家公司不会为了收加盟费而滥开店，我的品牌资产是被保护的
- 对**投资方**：规模化是有纪律的，不是无序扩张

**这一章同时替代了原「尚未验证三条」的全部功能**（股东第 12 条要求删除），信息相同，落点完全不同。

### 四个成熟度阶段（对外表述）

| 阶段 | 定义 |
|---|---|
| **产品定型** | 完成产品标准、工程标准、物资清单与造价模型 |
| **样板验证** | 直营样板店开业并达到设定的出租率、房价与利润率标准 |
| **模型复制** | 多店验证模型稳定性与跨城市适应性 |
| **规模开放** | 进入全面合作开放阶段 |

## 7. 待股东确认的三件事

### ⚠️ ① 双叮模式是否真实存在（影响第 21 屏，也影响整个战略叙事的强度）

股东澄清：**上海是单独的住小叮，住大叮落在北京。**

但住大叮设计手册第 2 页平面图标注「住大叮建筑面积 1530㎡」，**同一层的灰色区域标注「住小叮」**——
两个品牌在同一栋建筑同层。若该图纸对应的是北京项目，则同物业高低配是真实存在的。

**需要确认：那张平面图对应的北京物业，是否真的同时布置了住小叮与住大叮？**

- **若是** → 强烈建议提升为集团级战略能力，命名「双叮模式」，并往前放。理由：产品能抄、价格能抄、装配式能抄，但"一个物业跑两个价格带、共享公区与后勤"需要两个成熟品牌加一套统一运营系统，单一产品线的竞品做不到。它把叙事从「我们有五个牌子」升级为「**我们的品牌可以组合使用**」
- **若否** → 第 21 屏删除，Ⅳ 章缩为 6 屏

### ② 「已完成上海杭州首批门店布局」的表述

股东第 9 条确认采用此表述。**这个措辞是可以站住的——「布局」涵盖签约与选址完成，不等于「已开业」**，
与 36氪 既有公开报道也一致。但若现场被追问具体门店，需要有准备。

### ③ 住大叮的投资口径

住大叮尚无成本数据。定稿框架中第 11 屏的三层口径**仅标注为住小叮口径**，
住大叮部分暂不出现投资数字。成本表出具后再补。
