# 项目宪法（Project Charter）

> 本文件是最高层背景，很少变更。变更需股东确认并记入 decision-log。

## 1. 业务背景

- 股东是极简超经济型酒店品牌「**住小叮**」的股东之一，负责公司全部数字化建设、品牌建设与市场营销。
- 股东另成立了一家独立 AI 公司（网站 intent-computing.com），已开发产品 **Hotel Agent**：
  面向酒店团队的 AI 运营工作台（桌面应用，截至 2026-07 为 v0.0.4），整合 OTA 后台浏览、
  经营数据解读、竞对监控、门店质检、智能回复（评价回复）、调价建议等能力。
  对应"数字员工"概念：收益智能体、评价回复智能体、质检智能体、一键调价智能体。

## 2. 商业构想（待验证）

- **免费**提供 C 端智能体对接服务：基于 A2A 协议、MCP、Skills 的链接，让普通个人智能体能找到并预订酒店。
- **免费**赠送一套基于智能体逻辑开发的微信小程序，帮酒店搭建 AI 时代的智能体交易渠道。
- **收费**点：数字员工（收益/评价回复/质检/一键调价等智能体），按所需"员工数"收费。
- 定位口号：「**全球首家 0 手续费 A2A 订房平台**」。
- 产品下一步：**卡片体系** —— 不依赖用户对话，各智能体像数字员工一样主动推送消息（打工人身份）。

## 3. 六个待验证假设

| 编号 | 假设内容 |
|------|----------|
| H1 | 平台型公司未来会消失，交易将转为 A2A 方式（个人智能体 ↔ 企业智能体直接交易） |
| H2 | OTA 转型会很痛苦（让用户与酒店直接交易会降低其利润），因此短期内不会自我革命，留下窗口期 |
| H3 | 微信即将推出"微信智能体"，可直接调用所有小程序完成交易和服务，这是重大渠道机会 |
| H4 | "免费接入 + 免费小程序 + 按数字员工数收费"的商业模式成立 |
| H5 | 「全球首家 0 手续费 A2A 订房平台」定位成立（确实是首家；0 手续费可持续） |
| H6 | 卡片体系/主动推送（数字员工主动干活）是正确的产品形态方向 |

## 4. 当前任务目标

1. **毫不顾忌成本**地深度研究验证 H1–H6 与整体商业模式是否成立；结论要**直接、不留情面**。
2. 以三层记忆架构维护本仓库，保证任务可跨对话延续。

## 5. 已确认的研究约束（股东决策，2026-07-19）

- 地域：**中国与全球并重**（两个市场同等研究深度）。
- 数据：本轮**纯外部推演**（行业公开数据），不使用内部数据；后续可补充校准。
- 语言：全部产出为中文。

## 6. 定位修订（股东确认，2026-07-24）

验证报告判决后，股东**接受定位改写**：公司定位从「全球首家 0 手续费 A2A 订房平台」改为
「**帮中国单体/中小酒店在 AI 渠道把房卖出去的服务商**」——第一收入曲线为微信 AI 接入改造（一次性+年费），
第二收入曲线为收益/调价数字员工（**按结果计费**，不按员工数）；评价回复/质检降为免费引流；
免费小程序仅作获客钩子且严控免费池规模；客群上移至单体中端/精品+小连锁；住小叮做可量化样板。
原「平台」表述自此废止（详见报告第八节与 decision-log 2026-07-24）。

## 7. 已知内部数据（股东提供，2026-07-24）

- 住小叮直订占比：约 **15%**（OTA 约 85%）
- AI 公司签约/试用酒店数：**0**（冷启动从零开始）
- 数字员工定价：**未定**（待按结果计费试点确定）
