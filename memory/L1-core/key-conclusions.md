## 六大假设判决（2026-07-19，纯外部推演）

| 假设 | 判决 |
|------|------|
| H1 平台会消失、A2A取代平台 | **不成立**（3–5年内）。二十年六波去中介化全败；OpenAI 2026-03撤回旅行站内结账；OTA业绩创纪录；所有AI入口交易均路由经OTA。长期弱形式（获客重构、OTA后端化）可押注 |
| H2 OTA不自我革命、留窗口 | **大部分不成立**。OTA是AI入口最激进拥抱者（ChatGPT/微信AI首批全是OTA）；只革交互不革佣金。真窗口=89%酒店未agent-ready的供给侧改造服务，约12–24个月 |
| H3 微信智能体机会 | **方向成立**（已应验：2026-06-08官宣、小微6-20灰度、Q3预计放量），但①非"所有小程序"（须自愿接入+过审）②首批红利归OTA巨头③规则黑箱+腾讯持同程20.46% |
| H4 免费接入+小程序+按数字员工收费 | **原始形态不成立**。送小程序≠送流量（现实直订仅5–15%）；按员工数订阅中小B无先例；评价回复/质检被平台免费化；唯一可收费空白=收益/调价（RMS渗透<0.5%），须按结果计费 |
| H5 全球首家0手续费A2A订房平台 | **不成立**。同构在先者：Lighthouse/THN（订阅+0佣金ChatGPT直订App）、Selfbook、DirectBooker、SiteMinder、inHotel（A2A协议）、京东0佣金。"全球首家"违反《广告法》。0手续费=无担保是C端信任硬伤 |
| H6 卡片体系/主动推送 | **方向成立（有条件）**（2026-07-24专项补课后上调）：美团主动管店/飞猪商家助理/钉钉数字员工/ChatGPT Pulse等行业集体收敛到此形态；携程全自动调价被监管逼退使"老板一键确认"成唯一合规形态。五个硬约束：确认制须做成通往自动托管的阶梯、频次每日≤1-3条、微信通道走订阅消息授权飞轮（个人微信自动化是红线）、防橡皮图章需内置质量仪表、只推高置信度建议（采纳率锚20-40%）。详见报告§十二与raw/19-23 |

## 商业模式判决

- 纯订阅模式：目标客群19.8万家非连锁经济型（收缩中）；可行价带仅200–300元/月/店；打平需3500–4000家付费店→3.5–4万家免费店→资金需求8000万–1.5亿/3–5年。**先例（客如云/二维火/微盟/有赞）全灭，不成立**
- 修正方案（可辩护）：①定位改"酒店AI渠道服务商"；②第一曲线=微信AI接入改造（一次性+年费，时效最强）；③第二曲线=收益/调价数字员工**按结果计费**；④评价/质检降级为免费引流；⑤免费小程序仅作钩子、绝不承诺带单；⑥客群上移至单体中端/小连锁；⑦住小叮8–12周产出可审计的"多卖房"数据；⑧终局=利基龙头或被并购的卡位资产（对标Lighthouse估值$10亿+）

## 关键事实锚点

- 微信AI：2026-06-08《开发者接入微信AI生态指引》（mcp.json/SKILL封装+审核制）；首批内测美团/携程/同程/滴滴/京东；小微6-20灰度一级入口；AI专属卡6-17发布；全量取决于监管（2026-07-15智能体新规）
- 中国供给：住宿设施34.9万家；单体25.5万家；经济型77.8%；单体OTA客源>70%；云PMS渗透仅10%
- 佣金：携程10/12/15%三档+推广后综合15–25%（个案30–40%）；美团6–10%；抖音8%；住宿有效佣金口径约8–10%（勿用全业务货币化率4.4%——含机票低佣业务）；2026-01携程被反垄断立案
- 付费意愿：单体经济型软件成交价带1000–6000元/年；全国核心PMS盘子仅19–20亿/年；RMS渗透<0.5%
- 竞对锚点：SiteMinder 5.3万家酒店双MCP产品线；Lighthouse 7万家/估值$10亿+；LiteAPI为OpenAI供酒店底层；国内京东0佣金、美团既白免费AI工具
- 履约/合规：不碰资金=唯一免牌照路径（二清红线）；仅12%消费者接受agent自主支付；平台负商户核验义务（文旅部令第4号）
