# 住小叮团队歌三首 · Suno v6 高级模式成品包（2026-09-16）

> 依据：股东十答（decision-log #22）+ Suno v6 调研（raw/36）+ 校对智能体逐字审查（多音字/韵脚/句长/歧义）。
> 三首对应三种用途：A 年会团建齐唱 / B 股东录音棚录制 / C 对外发布品牌曲。全部可对外发布。

## 〇、老板唯一硬伤"音太高"的对策（三首通用）

Suno 无法用提示词精确指定调性或最高音，只能"多管齐下 + 试唱筛选"：

1. **人声性别选 Male**（男声版整体调门更低；混声靠风格框里的 group vocals 描述）。
2. **风格框写死音区**：`comfortable low-to-mid register, melody within one octave, no high notes, no belting, no falsetto, sung by everyday people not trained singers`。
3. **排除风格**：`falsetto, high belting, soprano, screaming, key change`。
4. **歌词层面已处理**：三首句尾全部是 ao / ang / ai 开口韵，长音不发紧；副歌首字避开窄元音（A 首字"说"安全；B 把品牌名挪到副歌末句，起句改"让"；C 的"叮"要求唱成短促重音而非长高音）。
5. **筛选办法**：每首出 6–8 个候选，让 2–3 个"不会唱歌的人"跟着副歌哼，哼不上去的版本直接淘汰；这是唯一可靠的检验。
6. **兜底**：B 歌进录音棚时让录音师把伴奏整体降 2–3 个半音（专业标准操作），A 歌团建也可以用这条降调伴奏。

## 一、通用操作设置（每首都一样）

| 项 | 设置 | 说明 |
|---|---|---|
| 模式 | **高级模式**（界面写 Custom 或 Advanced） | 唯一有歌词框的模式 |
| 模型 | **v6**（不用 v6-wild） | wild 只用来探索 |
| Variety | **Off / 0** | 否则 Suno 会改写你的风格提示词 |
| Style Influence | **80** | 贴合风格框 |
| Weirdness | **40** | 偏保守，减少走音 |
| Vocal Gender | A、B 选 **Male**；C 不选（男女对唱） | 降调门 |
| Duration | Custom：A 2:40 / B 3:10 / C 2:50 | 到点硬切，宁多 10 秒 |
| Max Mode | 草稿关；定稿那一轮**开** | 20 积分/次 |
| 生成轮数 | 每首 3–4 轮（6–8 个候选） | Pro 2500 积分足够 |
| 下载 | 只下载定稿（Pro 每月 20 次） | 迭代时用在线试听 |

流程：粘贴 → 生成 → 试唱筛选（见〇-5）→ 逐句对词记错字 → 错字用 v6 的"改一句/一个词"功能修，不行就换同音字重抽 → 定稿开 Max Mode 再抽一次 → 官方下载 WAV + MP3。
B 歌定稿后额外做一件事：用 Suno 的分轨（Get Stems）导出**纯伴奏**和**人声导唱**两条轨给录音棚。

## 五、如果 v6 把方括号里的英文念出来了

v6 首周社区反馈之一是"把指令唱出来"。若出现：把每个方括号缩成裸标签（`[Verse 1]` `[Chorus]` `[Bridge]` `[Outro]`），所有演唱描述移到风格框末尾，例如在风格框追加 `verses by one male lead, chorus by full group unison`。其余不变。

## 六、校对已处理的坑（供以后写歌复用）

- 同音歧义：一声早安 → 一句早安（"医生"）；住小叮人 → 住小叮（"叮人"）；想走的人 → 想飞的人（团建语境=想离职）；叮 一声 → 叮的一声（"丁医生"）。
- 多音字：答应 → 承诺；模样 → 担当；背起 → 拎起；省下 → 多出；迎着 → 迎向；出发 → 启程（A 桥段）。
- 重韵/破韵：闪耀×2、在/在、漂亮/闪亮、来/来、精彩×2 已错开；C 桥段第三句改押 ai。
- 句长：三首每段内行长已对齐（A 全 8；B 主歌 7 副歌 8 桥 9；C 主歌 7/9 副歌 9/9/8/8 桥 8）。
- 副歌品牌名一律落在末句；全曲 4–5 次。
