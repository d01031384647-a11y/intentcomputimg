## 官方公开信息（搜索引擎索引）

- 文档页：https://www.intent-computing.com/hotel-agent/doc/ （中文）/ en-sg.html（英文）
- 产品定义（官方元描述）：Hotel Agent 是面向酒店团队的 AI 运营工作台，将 OTA 后台浏览、
  经营数据解读、竞对监控、门店质检、智能回复、调价建议整合进一个桌面应用（Windows/Mac）。
- 版本：0.0.4（截至 2026-07）

## 股东描述的产品与商业构想

- 已尝试的功能：收益智能体、评价回复智能体、质检智能体、一键调价智能体。
- 免费部分：
  1. C 端智能体对接（A2A 协议 / MCP / Skills），让个人智能体能找到酒店并交易；
  2. 基于智能体逻辑的微信小程序（送给酒店）。
- 收费部分：数字员工按"员工数"收费。
- 定位：「全球首家 0 手续费 A2A 订房平台」。
- 下一步：卡片体系——智能体像数字员工一样主动推送消息，不依赖用户对话发起。

## 母体业务

- 「住小叮」：极简超经济型酒店品牌（中国）；股东负责其数字化/品牌/营销。
