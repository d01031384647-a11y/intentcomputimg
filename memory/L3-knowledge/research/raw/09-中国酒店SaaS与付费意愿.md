# 09-中国酒店SaaS供应商格局与单体经济型酒店IT付费意愿（H4市场基础）

> 研究日期：2026-07-19 ｜ 方法：WebSearch 17次（中英文混合）｜ 信息分类标注：【事实】【公司宣传】【媒体推测】

## 概述

本维度回答核心问题：**一家单体经济型酒店今天每年真实愿意为软件付多少钱？"按数字员工收费（每员工每月200-1000元）"是否落在付费意愿区间内？**

结论先行：
1. 中国酒店SaaS市场的真实成交价带高度分层：民宿/小酒店 PMS **免费~4000元/年**；单体中小酒店 PMS **2000-6000元/年**；带模块的中端方案（别样红）**5000-20000元/年**；中高端/集团（绿云、石基）**约8800元-数万元/店/年**。
2. 中国酒店 IT 支出占营收约 **1.2%**，仅为欧美（4.6%，2019）的约1/4；中国SaaS整体客单价与美国差距巨大（IT支出中SaaS占比<3% vs 美国>7%）。
3. 一个关键锚点：**美团把面向小酒店的PMS"住满满"定价为1000元/店/年（约83元/月）**——这是巨头判断的小酒店软件付费能力上限附近。
4. "每数字员工200-1000元/月"（=2400-12000元/年/员工）：**单员工低档价勉强触及单体经济型酒店现有软件总支出的上限；多员工或高档价（1000元/月）超出现有价带2-10倍**。要成立，必须按"替代人力成本/直接创收"逻辑卖，而非按"软件工具"逻辑卖——云迹科技的例子表明酒店确实愿为"替代人力"付费，但其主要成交形态是硬件（机器人），纯软件/AI系统ARPU依然很低（估算<2000元/店/年）。

## 关键发现

### A. 头部供应商格局与经营状况

1. 【事实】**石基信息（002153.SZ）2024年**：酒店信息管理系统业务营收 **9.38亿元**；可重复订阅费（ARR）**5.23亿元**，同比+25.1%（2023年为4.18亿）；企业客户门店总数超 **8万家酒店**，平均续费率超90%；海外收入占比升至20.34%。但公司整体 **2024年度预亏1.4-2.2亿元**——中国酒店IT龙头在集团层面仍亏损。
   来源：https://static.cninfo.com.cn/finalpage/2025-04-29/1223378885.PDF ；https://m.hexun.com/stock/2025-01-23/217009566.html
   → 隐含单店软件ARPU：9.38亿/8万店 ≈ **1.2万元/店/年**（石基客户以中高端与集团为主，且含大量海外）。

2. 【事实】**绿云软件（赴港IPO）2024年**：营收 **3.27亿元**（同比-3.0%），净利润6897万，毛利率68%；服务超 **3.7万家酒店**（锦江、君亭及万豪、洲际等在华酒店）；2016年以来5轮融资累计超4亿元，D轮投后估值25.25亿元。
   来源：https://finance.sina.com.cn/jjxw/2026-02-26/doc-inhpcyyc0420387.shtml ；https://www.fengkouapp.com/news.html?id=1231293552697544704&type=news
   → 隐含ARPU：3.27亿/3.7万 ≈ **8800元/店/年**（客户偏中高端）。注意：营收在下滑，"住宿业数字化第一股"IPO两度受挫（【媒体推测】股权与增长成色问题，来源：https://finance.sina.com.cn/jjxw/2024-11-14/doc-incvzmwi0359468.shtml ）。

3. 【事实】**别样红（美团2018年5月全资收购）**：不免费。付费商家反馈实际价格 **5000-20000元/年**（首年初装费+次年起年费，按业态/房量/模块定价）；2017年底签约酒店1.4万家。
   来源：https://byh.xcpms.com/index.php/post/414.html ；https://www.traveldaily.cn/article/97829/ ；https://m.traveldaily.cn/article/122240

4. 【事实·重要锚点】**美团免费PMS"住满满"于2024年2月1日起结束免费，定价1000元/店/年**（2024年1月31日前付费享800元/店/年优惠）。曾因免费+直连美团受小宾馆欢迎。
   来源：https://byh.xcpms.com/index.php/post/456.html
   → 双重含义：(a) 巨头也无法长期承受免费PMS，免费模式本身被证伪一次；(b) **1000元/年 ≈ 83元/月是美团对小酒店付费能力的定价判断**。

5. 【事实】**订单来了（民宿/小酒店PMS，宣称15-20万商家）**：基础版免费（赠间夜额度）；专业版 **≤20间房 3998元/年**，每增1间+100元/年，首年另收2000元实施费；永久买断16800元起。
   来源：https://www.dingdandao.com/price ；https://zhuanlan.zhihu.com/p/719339553 ；https://www.traveldaily.cn/article/147066

6. 【事实】**金天鹅（单体中小酒店PMS主力厂商，同程艺龙战略投资）**：主打三星以下、50-150间房酒店，费用"几千到几万"；2017年买断制报价2980-6000元/点，硬件接口每个2000元。
   来源：https://www.zhihu.com/question/56203795 ；https://www.carzyuncle.com/1868.html ；http://www.guojialvye.com/cb/lyzx/5855.html

7. 【事实】**番茄来了（美团2015年入股，SIG/美团投A+轮）**：覆盖约5.5万家客栈民宿（【公司宣传】），具体价格未公开。
   来源：https://lieyunpro.com/archives/80093

8. 【事实】**众荟（携程系）**：2015年携程将中软好泰+慧评网重组为众荟；2018年再重组后PMS（慧云/众荟管家）与入住通归携程，众荟保留大数据平台（口碑管理"慧评"、收益管理"RMS+"）。慧评/RMS+订阅价未公开；市场上第三方质检服务单次5000-20000元。
   来源：https://36kr.com/p/1722659618817 ；https://m.traveldaily.cn/article/146825

9. 【事实】**云迹科技（酒店机器人龙头，2025年10月16日港股上市，开盘涨约50%）**：2022/2023/2024营收1.61/1.45/2.45亿元，三年累亏8.15亿；2024年酒店场景占营收83%；**机器人及功能套件收入1.89亿（77.2%），AI数字化系统收入仅5588万（22.8%）**；覆盖约3万家酒店。机器人均价持续下探："格格"26800→20900元、"润"23200→13100元（2022→2024）、UP系列5.42万→2.23万元。"租赁+订阅"收入三年CAGR 45.5%。
   来源：https://finance.sina.com.cn/stock/hkstock/hkzmt/2025-10-16/doc-inftzxpv7444674.shtml ；https://news.qq.com/rain/a/20250402A09PZX00 ；https://finance.sina.com.cn/roll/2025-04-10/doc-inesrsta3404033.shtml
   → **硬件vs软件付费意愿对比**：酒店愿意为一台1.3-2万元、看得见摸得着、直接顶替夜班送物人力的机器人一次性付费；但AI软件系统ARPU估算仅约1800元/店/年（5588万/3万店），且龙头三年亏损超营收。

### B. 付费能力与付费意愿的宏观证据

10. 【事实】**中国酒店IT支出占营收约1.2%，欧美从2013年2.8%升至2019年4.6%**；国内五星/四星酒店IT投入仅占0.7%/0.5%（2019），且多年几乎不变。
    来源：https://www.shijigroup.cn/blog/75.html （石基集团引用行业数据）；https://m.traveldaily.cn/article/180805
    → 对80间房、ADR 180元、出租率60%的单体经济型酒店（年房费收入约315万元），1.2%≈**3.8万元/年的全部IT预算**（含硬件、网络、门锁等），纯软件只是其中一部分——与上文2000-6000元/年的软件价带互相印证。

11. 【事实】**中美SaaS付费差距**：中国IT支出中SaaS占比不到3%（美国超7%）；媒体广泛引用"客单价相差上百倍"；原因：人力便宜替代软件、企业净利率低（5-6% vs 美国10%+）、中小企业年死亡率约30%、平均生命周期3-5年。
    来源：https://www.chinaventure.com.cn/news/108-20230426-374939.html ；https://www.thepaper.cn/newsDetail_forward_24895443

12. 【事实】**餐饮SaaS对照组**（商户规模、客单价与经济型酒店高度可比）：二维火基础功能免费、付费版年费约2000-4000元；客如云2020年被阿里仅以8亿元收购；头部厂商（雅座、二维火、客如云）曾集体裁员降薪；商户"实用主义"，费用略高即流失。
    来源：https://news.qq.com/rain/a/20200118A0BLNE00 ；https://m.mpaypass.com.cn/news/201906/10142756.html ；https://www.keruyun.com/industrynews/2437.html
    → 中国小商户软件付费天花板约在**2000-4000元/年**，跨行业一致。

13. 【事实】**酒店真正大额付费流向OTA佣金而非软件**：携程酒店佣金10%/12%/15%三档，美团8%/10%/12%三档，抖音2024年7月起4.5%→8%；每间夜佣金携程约42.6元 vs 美团13.3元。测算：80间房单体经济型酒店若30%订单来自OTA，年佣金支出约8-12万元——**是其软件年支出的20-40倍**。
    来源：https://www.21jingji.com/article/20250304/herald/66283470c28cce600ee39fd0dc0ac01e.html ；https://finance.sina.com.cn/jjxw/2025-02-28/doc-inemzcmr2468212.shtml
    → 酒店愿为"带来客人"付大钱，为"管理工具"只付小钱。数字员工若被感知为"工具"，进入2000-6000元价带；若被证明"直接创收/省人头"，才可能突破。

14. 【事实】**市场基数与渗透率**：2024年底全国酒店34.9万家，其中非连锁25.54万家（门店连锁化率26.75%）；经济型（二星及以下）27.1万家、占77.8%；经济型客房连锁化率约30%。2025年底客房连锁化率升至41.8%。PMS渗透率2026年已超82%（2020年不足60%）【媒体推测，来源为厂商生态文章，需谨慎】；2023年PMS市场规模：传统PMS 53.47亿 + 云PMS仅6.05亿。
    来源：https://www.chinahotel.org.cn/articles/17173 ；https://finance.sina.cn/2026-04-24/detail-inhvqwcw4422001.d.html ；https://www.chyxx.com/industry/1216424.html ；https://www.jtepms.cn/post/215.html
    → 云PMS全国市场一年仅6亿元——这就是"卖软件给中国酒店"的现实盘子；同时约18万家非连锁经济型酒店确实是无人服务的空白市场。

### C. AI数字员工的供给侧动向（竞争与替代）

15. 【事实】**集团自研免费化**：锦江2025年发布AI超级员工"JINTELL"、首旅如家有"AI数字店长"（收益、点评、知识搜索等6大能力）、东呈打造AI店长助理/前台助理等智能体矩阵——大集团自研自用，不构成第三方付费市场，且拉高单体酒店对"免费/内置AI"的预期。
    来源：https://m.traveldaily.cn/article/188645 ；https://www.shijigroup.cn/blog/136.html ；https://www.donews.com/article/detail/8173/82777.html

16. 【事实】**OTA与免费大模型的双重挤压**：携程与雅里数科推"灵犀点金"收益管理智能体（OTA生态内提供）；DeepSeek类免费/低价大模型使差评回复效率提升70%、处理时间缩短40-60%，媒体判断中小酒店将"直接购买基于云服务的DeepSeek方案"或用免费工具自助完成点评回复/文案。
    来源：https://m.traveldaily.cn/article/188645 ；https://www.ctnews.com.cn/chanye/m/content/2025-02/20/content_170681.html ；https://m.thepaper.cn/newsDetail_forward_30156078
    → **"评价回复智能体"单独收费的空间正被免费通用AI快速侵蚀**；收益管理/调价类因需数据接口与实时性，护城河略高。

17. 【事实】**行业下行压缩付费能力**：2024年前三季度行业出租率-2%、房价-4%、RevPAR-6%；经济型酒店集团ADR约180-212元（2023-2024）。
    来源：https://www.tripvivid.com/deep/44678.html ；https://m.mp.oeeee.com/a/BAAFRD000020240408931644.html

## 对相关假设的含义（主要H4，兼及H5/H6）

**H4（免费接入+免费小程序+按数字员工订阅收费）——市场基础薄弱，定价上限严苛：**

- **真实价带判决**：单体经济型酒店全部软件年支出的真实成交带约为 **1000-6000元/年**（美团定价锚1000元、订单来了3998元、金天鹅几千元、餐饮SaaS对照2000-4000元）。别样红5000-20000元/年已是"中端天花板"，绿云8800元ARPU来自中高端客户。
- **按"每数字员工200-1000元/月"折算=2400-12000元/年/员工**：
  - 1个员工×200元/月（2400元/年）：落在价带内，可行但对获客成本要求极高；
  - 1个员工×1000元/月或3个员工×任意档：1.2万-3.6万元/年，**超出单体经济型酒店现有付费意愿2-10倍**，仅中高端/连锁客户可承受——而这类客户正被集团自研AI和石基/绿云占据。
- **正面证据**：石基ARR+25%、云迹"租赁+订阅"CAGR 45.5%、住满满敢于从免费转向收费——表明酒店订阅付费在增长；云迹证明"替代人力"叙事能让酒店掏钱（但主要以硬件形态成交）。
- **反面证据（更重）**：全国云PMS盘子仅6亿/年；行业龙头石基集团亏损、绿云营收下滑、云迹三年亏8亿；免费通用AI（DeepSeek）正在把"点评回复"这类轻任务的价格打到零；锦江/首旅/东呈自研AI数字员工免费内置。
- **对免费策略本身的警示**：美团（住满满）和携程系（住哲、云掌柜等曾宣布免费）都试过免费PMS，最终美团回归收费——免费获客在该行业被验证过、也被放弃过；"免费接入+免费小程序"的获客逻辑并不新，关键差异只在后端变现产品是否真的能创收。
- **可行路径推论**：定价必须锚定"替代0.5-1个人力"（经济型酒店前台/保洁月薪约3000-5000元）或"提升RevPAR可量化收益"，并优先做**收益管理/调价**（数据护城河高、直接创收）而非**评价回复/质检**（免费AI替代性强）。H6的"数字员工"形态若按≤300元/月/店的单一打包价切入18万家非连锁经济型酒店，理论市场约6.5亿/年——与整个云PMS市场同量级，天花板真实但不高。

## 证据缺口

1. 番茄来了、众荟慧评/RMS+的具体订阅价格未公开，无法补全民宿与点评管理两个细分的价带。
2. 云迹机器人"租赁/订阅"的月费具体价格（业内传约500-3000元/月）未找到权威来源，而这是"按月为数字劳动力付费"最直接的对标。
3. 缺少2025-2026年针对单体酒店软件支出的一手调研/问卷数据（现有IT占比数据停留在2019年）。
4. 石基/绿云面向经济型单体的低端产品线价格未拆分，ARPU推算掺杂中高端客户。
5. PMS渗透率82%（2026）出自厂商生态文章，权威性存疑，需交叉验证。
