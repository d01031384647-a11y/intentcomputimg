## 一、概述与总判断

围绕"客房/公共区一键呼叫 → 桌面引擎（数字员工）接收并派单"这一需求，可行技术路线共四条，按推荐优先级排序：

1. **Zigbee 按钮 + 自有网关（zigbee2mqtt/ZHA）路线 —— 首选。** 买涂鸦生态白牌按钮（TS0041/TS0044 公版）或 SONOFF SNZB-01P，**不用厂商网关**，自配 Zigbee USB 协调器（如 SONOFF ZBDongle-E，百元级）+ 开源 zigbee2mqtt，事件以 MQTT 直接进本地桌面引擎。单击/双击/长按三种动作在 zigbee2mqtt 设备库中均有公开支持记录。完全本地、零云依赖、零 API 授权费，按钮单价 25-50 元，无起订量压力。
2. **Aqara 绿米路线 —— 品质备选。** 深圳本地总部可拜访，无线开关（单击/双击/长按）成熟，官方有云端 HTTP API 和网关局域网协议（GitHub 公开），也兼容 zigbee2mqtt。单价略高（零售 69-99 元，贴目标价上限）。
3. **BLE 按钮/Beacon 厂路线 —— 差异化备选。** 深圳 MOKO、云里物里（Minew）等 Beacon 厂有现成"SOS/紧急按钮"品类（MOKO B1 明确写了酒店防侵扰场景），提供 SDK/协议文档，OEM 小批量友好；但需自建 BLE 网关层，工程量比 Zigbee 路线大。
4. **433MHz 餐饮服务铃路线 —— 不推荐作主线。** 迅铃（SINGCALL）等是现成"按铃→接收主机"产品，便宜且免布网，但生态封闭：搜索未找到任何公开 API/串口协议文档，且迅铃厂家在山东烟台而非深圳。若用需自行做 433 信号桥接（如 RF Bridge 方案），属于"能用但脏"的路线，只适合当价格谈判的锚。

**模组自研路线**（安信可 BLE 模组 3-10 元 + 自贴外壳）BOM 可压到 15-30 元，但涉及结构件、认证、产线，与"几万元级采购量"不匹配，POC 阶段不建议，仅作为 45 店后若上量的远期选项。

**深圳行建议拜访优先级：** 松诺 SONOFF（南山西丽，有具体地址）→ 绿米 Aqara（深圳总部）→ 酷宅科技（eWeLink 开放平台）→ 易百珑（宝安沙井，自发电开关，客房免电池卖点）→ MOKO / 云里物里（BLE 按钮备选）。

## 三、分类详情

### 路线 A：涂鸦 Tuya 生态（平台 + 白牌按钮厂）

**平台侧（涂鸦智能）**
- 涂鸦有 Zigbee 场景开关接入标准，单击/双击/长按是标准化的触发类型，每种可绑定不同场景；生态内按钮产品普遍具备三动作。来源：涂鸦开发者平台场景开关接入标准（https://developer.tuya.com/cn/docs/iot/tuya-zigbee-scene-selector-access-standard?id=K9ik6zvma9qh6 ）；产品实证见 MOES 场景开关（https://moeshouse.com/collections/zigbee-scene-switch ）、Hubitat 社区（https://community.hubitat.com/t/strange-mode-switching-on-moes-zigbee-smart-button-scene-switch/109646 ）。
- 【确认】走涂鸦官方通道 = 必须涂鸦云：云开发按订阅计费（IoT Core 基础版设备上限 1 万个，含每月约 0.7 亿次 API 调用额度），事件经涂鸦网关上云后由云 API/消息订阅下发。来源：涂鸦产品定价（https://developer.tuya.com/cn/docs/iot/membership-service?id=K9m8k45jwvg9j ）、IoT Core（https://www.tuya.com/cn/platform/clouddev/iot-core ）。
- 【确认】涂鸦"本地联动/局域网联动"只是网关内部执行场景的机制，不等于给第三方开放 LAN API。来源：TuyaOS 本地联动文档（https://developer.tuya.com/cn/docs/iot-device-dev/tuyaos-gateway-local-linkage?id=Kc5xcmw9dasl6 ）。
- **规避云依赖的关键玩法【确认】：抛开涂鸦网关，把涂鸦生态 Zigbee 按钮直接配对到自有协调器 + zigbee2mqtt，事件走本地 MQTT。** 公版单键 TS0041、四键 TS0044 均在 zigbee2mqtt 官方设备库，动作含 single/double/hold。来源：https://www.zigbee2mqtt.io/devices/TS0041.html 、https://www.zigbee2mqtt.io/devices/TS0044.html 。

**白牌按钮厂（价格底线）**
- 深圳 Everlead Electronics：4 键涂鸦 Zigbee 场景开关 $9.9-13.9，MOQ 10 件；另有厂商阶梯价 $4.20（2-199 件）→ $3.50（1 万件+）；也有 $5.8-6.5、MOQ 50 件的量产报价；RSH-Tech、Shenzhen Wale 等 MOQ 低至 2 件。来源：Made-in-China 汇总检索（https://www.made-in-china.com/manufacturers/zigbee-switch.html ）、Alibaba RSH 产品页（https://www.alibaba.com/product-detail/RSH-Tuya-ZigBee-Wireless-Scene-Switch_1600915600144.html ）。
- 零售参照：涂鸦 Zigbee 单键按钮 AliExpress 约 $4-8（https://www.aliexpress.com/item/4001194277026.html ）。
- 【待核实】丝印/logo 定制门槛：搜索未获得明确数字，行业惯例白牌丝印通常 100-500 件起，需逐家询价（1688 直接谈）。
- 结论：**按钮到手价 25-50 元完全可落在 30-100 元目标带内，POC 阶段甚至可直接零售渠道买样机，无任何起订压力。**

## 四、关键问题结论（对应筛选标准）

1. **单击/双击/长按能否区分并 API 上报？**
   - Zigbee 路线（涂鸦公版/SONOFF/Aqara）：【确认】三动作皆标准支持；经 zigbee2mqtt 后以 MQTT `action: single/double/hold` 字段上报，桌面引擎直接消费。
   - BLE Beacon 按钮：默认单击广播为主，多动作需定制固件【待核实】。
   - 433 服务铃：只有"哪个键被按"（服务/结账/取消），无按压类型区分，且不上报到开放接口。
2. **网关是否必须厂商云？**
   - 涂鸦官方通道：必须涂鸦云（订阅制）；**旁路：弃用涂鸦网关，用自有协调器+zigbee2mqtt = 完全本地**【确认可行】。
   - Aqara：云 API + 官方 LAN 协议双通道（LAN 协议 GitHub 公开）【确认】，也可 zigbee2mqtt 旁路。
   - eWeLink：以云 API 为主【确认】；本地化同样靠 zigbee2mqtt 旁路。
   - 推荐架构：每店一个 Zigbee USB 协调器插在桌面引擎主机/工控机上，zigbee2mqtt → 本地 MQTT → 数字员工派单；断网可用。
3. **小批量定制门槛？**
   - 白牌现货 MOQ 2-50 件【确认】；丝印/logo 一般数百件起【待核实-逐家询价】；固件级定制基本要上千件或 NRE 费【待核实】。POC 用现货 + 贴纸/亚克力面贴即可规避。
4. **价格带匹配？**
   - 白牌 Zigbee 按钮 25-50 元、SONOFF 约 50 元、Aqara 69-99 元、433 按钮 20-50 元——全部落在或低于 30-100 元目标带【确认】。45 店满配（假设 45×40=1800 只）按 40 元计约 7.2 万元，符合"几万元级"。

## 五、红线合规说明

本品类不涉及摄像头与人脸识别，红线风险为零；按钮部署于客房属"客人主动触发"交互，无隐私争议。唯一注意：433MHz/2.4G 发射设备采购时确认具备 SRRC 型号核准（白牌厂重点核查项）。
