# 12 - 零佣金订房平台先例与A2A/智能体订房竞品全球盘点（H5直接检验）

> 研究日期：2026-07-19 ｜ 方法：WebSearch 18次（中英文混合）｜ 本环境无法抓取网页原文，以下均基于搜索引擎索引摘要
> 信息分类标注：【事实】【公司宣传】【媒体推测】

## 概述

本维度回答三个核心问题：①"全球首家0手续费A2A订房平台"是否属实；②零佣金订房平台的历史存活率与死因；③0手续费模式的成本可持续性。

**核心结论预览：**
1. **"全球首家"宣称在严格意义上不成立**。截至2026年上半年，全球至少已有 Agentic Hospitality（TravelOS MCP + ChatGPT App，0佣金直连PMS）、The Hotels Network/Lighthouse（ChatGPT内首个酒店直订App，订阅制+0佣金）、DirectBooker（前Google Travel/Tripadvisor高管创办，直连AI平台）、Nuitee LiteAPI（为OpenAI提供酒店预订底层）、Selfbook（Perplexity/PayPal直订）、Sabre+PayPal+MindTrip（端到端agentic预订）等多个同类或高度相似的产品已经上线或宣布。零佣金+订阅费的组合（=本项目商业模式）已被 The Hotels Network 明确采用。仅在"明确基于Google A2A协议"这一狭义技术口径上或可保留"首家"话术，但这属于营销措辞而非实质壁垒。
2. **零佣金/低佣金订房平台历史存活率极低**，主要死因：双边冷启动失败、被在位OTA封杀供给、旺季锁不住房源、收入模式撑不住获客成本、母体输血停止。典型案例：Roomkey（六大酒店集团亲自下场，2020年停运）、今夜酒店特价（被携程封杀后2014年卖给京东）、去哪儿前台零佣金切客战（与携程合并后终止）、Bidroom（0佣金+会员费，2022年后无融资无运营新闻，现状存疑）。
3. **0手续费的可持续性取决于"谁付钱"**：OpenAI Instant Checkout 向商户收4%交易费，且2026年3月被曝在旅行品类收缩（用户到支付环节流失）；支付通道成本约2-3%；LLM推理与获客成本必须由订阅费覆盖——这正是"数字员工订阅"要独立承担的全部重量，与国内先例"直客通"（免费帮酒店开微信直销店+收SaaS服务费，服务1.7万家酒店、85%的五星酒店）模式最接近，说明该模式可行但已有强先例，并非空白。

## 关键发现

### A. "全球首家0手续费A2A订房平台"的反例清单（核心问题①）

1. **【事实】Agentic Hospitality 已发布 TravelOS MCP Server + Agentic Booking Engine + ChatGPT App**，直连酒店CRS/PMS作为唯一数据源，宣称"让品牌而非中间商处于AI预订中心"、酒店完整拥有交互/数据/预订，0佣金。这是与本项目最接近的直接竞品（差异仅在于用MCP而非A2A协议、面向ChatGPT而非个人智能体泛生态）。来源：https://www.hospitalitynet.org/news/4132086/agentic-hospitalitys-travelos-mcp-chatgpt-app-is-putting-brands-not-intermediaries-at-the-center-of-ai-bookings ；https://www.hospitalitynet.org/news/4131210/agentic-hospitality-launches-travelos-mcp-server-enabling-agentic-hotel-distribution-inside-ai-platforms

2. **【事实+公司宣传】The Hotels Network（由Lighthouse支持）2026年在ChatGPT内上线"首个酒店直订App"，明确采用"固定订阅费+0预订佣金"收费**——与本项目"免费接入+按数字员工订阅收费"在收费结构上同构，且已上线。来源：https://blog.thehotelsnetwork.com/connect-chat-gpt-app-launch ；https://www.mylighthouse.com/resources/blog/direct-booking-app-chatgpt-lighthouse

3. **【事实】DirectBooker：前Tripadvisor CEO Steve Kaufer与前Google Travel负责人Richard Holden创办**（2025年7月披露，融资200万美元），用MCP把酒店数据直接喂给ChatGPT/Gemini；2026年4月宣布签约全球十大酒店集团中的五家（含BWH、丽笙），ChatGPT App上线、Claude connector上线。其模式是把客人路由回酒店自己的预订引擎（该次预订0佣金），但DirectBooker本身按实际入住向酒店收佣金（"commission only on completed stays"）——即低佣金而非零佣金。来源：https://skift.com/2025/07/17/former-heads-of-google-travel-and-tripadvisor-form-ai-startup-to-head-off-online-travel-agencies/ ；https://www.businesswire.com/news/home/20260430324298/en/ ；https://www.phocuswire.com/news/distribution/directbooker-bwh-radisson-chatgpt-claude

4. **【事实+公司宣传】Nuitee/LiteAPI 已成为OpenAI酒店搜索预订的底层供应商**：LiteAPI Agentic 通过开源MCP server为ChatGPT内完整预订流程供货，覆盖300万+酒店，兼容ChatGPT/Claude/Gemini。注意其本质是批发商/API模式（赚房价差或接口费），不是零佣金，但它证明"智能体订房基础设施"赛道已有重量级在位者。来源：https://liteapi.travel/ ；https://nuitee.com/connect/liteapi-agentic ；https://skift.com/2025/09/09/nuitee-travel-api-connectivity/

5. **【事实】Selfbook（累计融资约4255万美元，Tiger Global/Amex Ventures投资）已实现从Perplexity单条prompt直订酒店，并为PayPal App内酒店预订供货（2025年6月起，触达4.34亿PayPal用户）**，定位是酒店直销支付与AI分发基础设施。来源：https://selfbook.com/info-hub/redefining-hotel-commerce ；https://www.crunchbase.com/organization/Selfbook

6. **【事实】GDS巨头已下场**：Sabre 2025年9月发布首批agentic AI-ready API + MCP server（航班/酒店/售后全流程）；2026年2月Sabre+PayPal+MindTrip宣布"旅游业首个端到端agentic AI预订系统"（Q2 2026上线，420+航司、200万酒店）；Amadeus亦有官方/社区MCP方案并发文讨论MCP/UCP标准。来源：https://www.phocuswire.com/sabre-api-agentic-ai-mcp ；https://amadeus.com/en/blog/articles/agentic-ai-travel-mcp-ucp-standards ；https://www.oag.com/blog/march-2026-the-month-agentic-travel-gets-real

7. **【事实】DerbySoft（德比软件）+ DirectBooker + 80 DAYS 合作**，用ARI源+MCP server把酒店实时房价/房态/直订链接送入ChatGPT、Claude、Gemini，2026年Q1 beta。DerbySoft还收购了AI自动化平台Arise。来源：https://www.eighty-days.com/blog/80-days-announces-strategic-partnership-with-directbooker-and-derbysoft/ ；https://www.hftp.org/news/4126091/

8. **【事实】RateGain 2025年末推出首个MCP-enabled booking engine**；Cloudbeds发布"酒店业首个基础AI模型"Signals及对话式界面Ask Signals（2026年5月），并将MCP列为PMS直连AI智能体的基础技术。来源：https://gimmonix.com/news/agentic-ai-is-coming-to-cut-otas-out-or-is-it ；https://www.globenewswire.com/news-release/2026/05/21/3299668/0/en/ ；https://www.cloudbeds.com/ai/

9. **【事实】OTA自身已接入智能体入口**：Booking.com是ChatGPT Apps首批应用之一，并于2025年10月发布自有agentic AI功能；行业媒体判断"ChatGPT直订=0%佣金时代"的论述已成公开叙事（otelciro等）。这直接削弱"OTA不会自我革命留下窗口期"的强形式（H2）。来源：https://news.booking.com/bookingcom-debuts-agentic-ai-innovations-adding-to-its-robust-suite-of-genai-tools-for-customers/ ；https://otelciro.com/en/news/chatgpt-hotel-bookings-0-commission-era-2026

10. **【媒体推测→事实混合】A2A协议在酒店业仍停留在讨论层**：Google 2025年4月发布A2A协议（50+伙伴），Hospitality Net多篇专栏讨论"从MCP到A2A"的酒店分销演进，但检索未发现任何一家已上线的"基于A2A协议的订房平台"。这意味着：狭义A2A口径的"首家"暂时说得通，但同时说明A2A订房的需求侧（个人智能体保有量与委托交易习惯）尚不存在。来源：https://www.hospitalitynet.org/opinion/4129485/ ；https://www.hospitalitynet.org/opinion/4129691/ ；https://www.ibm.com/think/topics/agent2agent-protocol

11. **【事实】国内竞争格局**：飞猪"问一问"（2025年4月，多智能体，可调用飞猪机酒库存直接出可预订方案，接入DeepSeek-R1+通义）、携程TripGenie（订单转化率为普通用户2倍）、阿里Qwen App（月活约16.6亿口径含全生态，可直接订机票酒店）、美团/滴滴/携程/同程为微信智能体首批内测方（2026年6月）。**未检索到国内"酒店MCP/A2A订房"独立创业公司**——最接近的是酒店集团自建智能体（德胧"神灯AI"、首旅如家"AI数字店长"覆盖6300家店做定价收益管理）。来源：https://m.traveldaily.cn/article/186670 ；https://finance.sina.com.cn/stock/stockzmt/2025-03-11/doc-inephsqc9555901.shtml ；https://companies.caixin.com/m/2026-06-09/102452577.html ；https://caifuhao.eastmoney.com/news/20260312095441949280560

12. **【事实】直客通（Zhiketong）是"免费/低门槛帮酒店开微信直销店+收SaaS与服务费"的最强中国先例**：2014年成立，IDG/红杉/顺为等多轮投资，2020年D轮5000万美元；服务1.7万+酒店及景区，宣称全国85%五星酒店选其作为微信直销伙伴，官方微信月交易额超7亿元。本项目"免费送小程序+订阅数字员工"与其高度同构（差异在AI含量与A2A入口）。来源：https://www.36kr.com/p/952686693759369 ；https://www.tripvivid.com/31682.html

### B. 零佣金/低佣金先例及结局（核心问题②）

13. **【事实】Roomkey——六大国际酒店集团（Choice/Hilton/Hyatt/IHG/Marriott/Wyndham）合资的"官方直订搜索平台"，2012年上线，2020年6月停运**。模式为搜索后跳转各品牌官网完成预订（绕开OTA佣金）。坐拥最强供给侧背书仍失败：需求侧无理由改变习惯、体验断裂、投入不及OTA。这是"供给侧发起的去中介化平台"最重要的死亡案例。来源：https://skift.com/2020/06/08/hotels-backed-online-search-platform-roomkey-suspends-operations/ ；https://en.wikipedia.org/wiki/Roomkey

14. **【事实】今夜酒店特价——2011年上线的尾房特价App，2014年1月被京东以千万美元级收购（现金+股票）而非独立存活**。关键死因：携程宣布"任何与今夜合作的酒店直接下架携程"实施封杀；旺季锁不住房源（"越有卖房能力的时候越没有房"）；只做手机支付导致20个支付用户19个失败；成本失控。创始人任鑫复盘承认"一半决策是错的"。来源：https://www.woshipm.com/it/81180.html ；https://www.traveldaily.cn/article/112214/ ；https://zhuanlan.zhihu.com/p/96286564

15. **【事实】去哪儿2015年"前台切客+零佣金"战役**：COO彭笑玫宣称"去哪儿对酒店零佣金，可为全国消费者每年省约100亿元"，用前台扫码发1000元红包切客。结局：携程用"钻石会员专享价"锁定高端客源+预付10亿元垄断如家/汉庭等经济型连锁库存反制，2015年10月携程去哪儿合并，零佣金战终止。证明：**零佣金作为进攻武器会遭遇在位者的库存锁定与资本合并**。来源：https://m.traveldaily.cn/article/84670 ；https://m.21jingji.com/article/20150404/3c48d78eb6f8358b32732042164db236.html

16. **【事实+现状存疑】Bidroom——全球最知名的"0佣金+会员费"订房平台（2016年宣布转向0佣金，2019年宣称12万+酒店、128国，会员费约$29-99/年，总融资约3000万美元级）**。2022年1月推出白标uGO后，未检索到任何后续融资、运营或关闭的新闻；2024年仅剩返利/评测类网站的存量介绍页。多次定向检索（含波兰语"upadłość"破产）均无法确认其当前是否仍在运营——一家平台若活跃不会连续4年零新闻，**倾向判断已停滞或名存实亡，但无法给出确凿关闭证据**（列入证据缺口）。来源：https://revenue-hub.com/bidroom-commission-free-booking-platform/ ；https://globetrender.com/2019/10/10/bidroom-cheap-hotels/ ；https://www.crunchbase.com/organization/bidroom ；https://www.cardrates.com/news/bidroom-offers-members-big-hotel-discounts-and-more/

17. **【事实】Costco Travel是"零佣金逻辑"唯一长期成功的变体，但它不是平台而是会员制折扣器官**：Costco把本可赚取的佣金让利给会员（每单省$500-1000），travel部门的角色是提升会员续费忠诚度；Costco 2024年会员费收入约48亿美元，占收入2%却贡献约73%毛利。**其成立前提是先有巨大的会员基本盘再做旅行，与冷启动的创业公司条件相反**。来源：https://www.mojosalesandbranding.com/post/costco-travel-benefits-2026-member-loyalty-brand-strategy ；https://newswirejet.com/costco-business-model/ ；https://upgradedpoints.com/travel/costco-travel-review/

18. **【事实（学理常识）】双边市场经济学**：交叉网络效应下，平台冷启动必须对一侧补贴（掠夺性定价/搭售隐性补贴是标准打法），冷启动期烧钱不可避免；中文平台经济学文献均确认"鸡生蛋"问题需以资本或既有流量池破解。本项目酒店侧免费=对供给侧补贴，但**需求侧（个人智能体用户）并不由本项目控制，补贴不解决"个人智能体何时大规模替用户订房"的问题**。来源：https://opinion.caixin.com/upload/pingtaibiji.pdf ；http://gjs.cass.cn/kydt/kydt_kycg/202301/t20230130_5584809.shtml

### C. 0手续费的成本可持续性（核心问题③）

19. **【事实】OpenAI Instant Checkout向商户收4%成交费（叠加Stripe通道费之上）**；ACP协议由OpenAI+Stripe共同制定。即：全球最大的智能体入口本身并不是"0手续费"，其分发是要收租的。来源：https://openai.com/index/buy-it-in-chatgpt/ ；https://stripe.com/newsroom/news/stripe-openai-instant-checkout ；https://www.ekamoira.com/blog/chatgpt-instant-checkout-agentic-commerce-protocol-2026

20. **【媒体推测（多源）】2026年3月OpenAI被曝收缩/下线旅行品类的直接结账（"Buy Now"）**：原因是旅行交易太复杂、用户愿意问建议但到输入信用卡环节即流失、回到信任的渠道下单。另有分析文章"OpenAI Killed Instant Checkout"讨论其失败不等于agentic commerce失败。**这是对"A2A交易闭环即将到来"最重要的反面证据：连ChatGPT都暂时没跑通旅行支付闭环**。来源：https://www.oag.com/blog/march-2026-the-month-agentic-travel-gets-real ；https://thesilkroadnexus.substack.com/p/openai-killed-instant-checkout-openais

21. **【事实】Google UCP（Universal Commerce Protocol）2026年1月对美国零售商上线**，Sabre/PayPal/MindTrip、Travelport TripServices（2026年7月测试解决"AI订票确认难"）等都在补交易闭环的确定性短板——说明**交易闭环基础设施2026年仍在成形期，"渠道尚未定型"是行业共识**。来源：https://www.orourkehospitality.com/insights/agentic-commerce-how-googles-ucp-opens-hotel-bookings-to-ai/ ；https://www.techtimes.com/articles/319558/20260702/ ；https://www.hospitality.today/article/the-channel-is-still-forming

22. **【事实】微信智能体已证实在推进且首批内测被大平台占位**：腾讯测试微信内嵌AI Agent（主界面右滑入口，自然语言调用小程序完成搜索-比价-下单-支付闭环，列为最高战略优先级）；财新2026年6月9日证实美团、滴滴、携程、同程为首批接入内测方。**对H3：方向证实；但首批生态位被OTA/大平台先占，"酒店直连微信智能体"未见通道，本项目并无先发独占**。来源：https://companies.caixin.com/m/2026-06-09/102452577.html ；https://www.huxiu.com/article/4863941.html ；https://finance.sina.cn/stock/jdts/2026-05-14/detail-inhxvpqt4077702.d.html

23. **【事实】AI直订流量真实在涨但基数小**：2026年ChatGPT外链调整后数周内酒店官网AI referral流量增长50%+；行业数据称直订份额趋势从22%走向30%（ehotelier 2026-07）。收益侧真实存在，但目前AI是"引流到官网"而非"智能体内闭环成交"。来源：https://insights.ehotelier.com/insights/2026/07/07/the-numbers-behind-ais-rise-as-a-booking-channel-for-independent-hotels/

## 对相关假设的含义

- **H5（全球首家0手续费A2A订房平台）：基本不成立**。0佣金+订阅费的智能体直订已有The Hotels Network（上线）、Agentic Hospitality（上线）等在先；基础设施层有LiteAPI/Sabre/DerbySoft/RateGain重兵。仅"明确用A2A协议"这一狭义口径可勉强称首，但A2A订房在全球都无落地案例，说明的是需求未至而非空白蓝海。建议定位改为"中国经济型酒店的智能体直连服务商"类可防守表述。
- **H2（窗口期）：被削弱**。Booking.com已是ChatGPT首批App并自建agentic功能；OTA在渠道成形期即占位（含微信智能体首批内测）。
- **H3（微信智能体）：方向证实，但首批红利归大平台**，酒店直连路径未开放。
- **H4（免费接入+订阅数字员工）：模式本身有直客通、The Hotels Network双重先例支持其可行性**，但也证明无独占性；历史教训（Roomkey/今夜/去哪儿）显示真正难点在需求侧与在位者反制，而非供给侧免费。
- **H1（OTA消失）：反面证据强**——OpenAI旅行结账收缩证明智能体交易闭环未成熟，OTA正在自我接入而非坐以待毙。

## 证据缺口

1. Bidroom确切结局（是否清算/被收购/僵尸化）无法从搜索摘要确认，需人工访问bidroom.com或波兰/荷兰工商登记。
2. "罗攀"未能识别（搜索仅命中"罗盘云PMS"，CEO李晓伦；疑为股东口误或指罗盘PMS），需股东澄清。
3. Agentic Hospitality与The Hotels Network ChatGPT App的具体定价、签约酒店数无公开数字，无法量化其先发规模。
4. OpenAI旅行结账收缩的一手确认（OpenAI官方未发声明，现有为行业媒体转述）。
5. 国内是否存在未被媒体报道的"酒店MCP/A2A"早期创业公司（搜索引擎对极早期项目覆盖不足）。
